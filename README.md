# Andrew Stormer's Portfolio

## Background

This is a Portfolio website that I have been developing throughout my senior year of college. The frontend of this website uses React and Tailwind CSS for styling, and the backend was created using NestJS and MySQL as a database. This application is hosted using Amplify (gen 1) with a serverless backend, with my NestJS backend in a AWS Lambda function that is interfaced by various Amazon API Gateways, and my database is stored in Amazon RDS.
